# PWA v1.0 — мобильная адаптация

## Исправления
- Принудительно заданы адаптивная ширина оболочки приложения и основных областей.
- Устранено сужение `.app-shell` на мобильных экранах; на телефонах оболочка занимает ширину viewport.
- Нижняя навигация растягивается на всю ширину телефона и учитывает safe-area iPhone.
- Навигация уроков остаётся в одну горизонтально прокручиваемую строку, названия могут переноситься внутри кнопки.
- Добавлены ограничения ширины и перенос длинного текста, чтобы карточки не расширяли страницу.
- Сохранены три цветовые темы и текущая структура учебных материалов.

## Технические проверки
- `app.js`: `node --check` — успешно.
- `manifest.webmanifest`: JSON прочитан без ошибок.
- Слайды 01–32: все файлы присутствуют.
- Service Worker cache key обновлён до `cp-negotiation-v10`, чтобы браузер получил новые CSS и оболочку.

## Проверка на устройстве
После публикации обновления откройте приложение с интернетом один раз. Если старая версия остаётся на экране, полностью закройте PWA и откройте повторно. Проверьте ширину на экране iPhone, прокрутку меню уроков, нижнюю навигацию и три темы. Реальный запуск на физическом iPhone в этой среде не выполнялся.
