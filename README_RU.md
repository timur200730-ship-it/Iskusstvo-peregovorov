# PWA «Искусство эффективных переговоров»

Автор: Тимур Хайретдинов. Бренд: «Центр Притяжения».

## Что входит в прототип
- 8 учебных модулей и 26 коротких уроков;
- галерея 16 доступных слайдов (№15, 17, 18, 20–32);
- инструменты: карта интересов, подготовка, BATNA, Win-Win, конструктор вопросов, уважительный отказ;
- заметки по урокам и свободные заметки;
- отметки прохождения и локальный прогресс;
- PWA manifest и Service Worker для установки и офлайн-доступа к оболочке, слайдам и рабочей тетради;
- PDF рабочей тетради, если он был доступен в рабочем наборе.

## Запуск локально
Нужен локальный веб-сервер (Service Worker не работает из `file://`):
- Python: `python -m http.server 8000`
- открыть `http://localhost:8000`

## Публикация
Можно разместить как статический сайт на GitHub Pages, Netlify или Vercel. Для GitHub Pages проверьте, что путь проекта корректно обслуживает `./` и Service Worker в пределах каталога приложения.

## Важно
Это первая функциональная сборка. Данные хранятся в localStorage на конкретном устройстве и браузере; облачной синхронизации, учётных записей и серверной панели пока нет. При очистке данных браузера локальные записи могут быть потеряны — используйте экспорт резервной копии. Галерея содержит только 16 исходных изображений, доступных в текущем рабочем наборе; остальные слайды нужно добавить отдельным этапом.
