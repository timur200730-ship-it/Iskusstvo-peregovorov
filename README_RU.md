# Искусство эффективных переговоров — PWA v0.9

Авторский практикум «Центра Притяжения», автор и ведущий — Тимур Хайретдинов.

Приложение содержит 8 модулей, 26 методически расширенных уроков, 32 слайда, шесть практических инструментов, рабочую тетрадь PDF, три цветовые темы, заметки, сохранение прогресса и офлайн-кэш.

Структура каждого урока включает цель, ключевые идеи, профессиональный и бытовой примеры, упражнение, вопросы для закрепления и мини-проверку с объяснением.
